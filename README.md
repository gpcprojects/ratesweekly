# RatesWeekly

Distribution point for the RatesWeekly desk application.

**This repository contains no source code.** It exists only to host the signed
release binary that the application's updater downloads.

- Source: private repository (Azure DevOps, JBDH Services).
- Releases: see the Releases tab. `RatesWeekly.exe` is the current build.
